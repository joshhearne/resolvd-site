`v0.12.0` is a small release: a handful of things that make day-to-day admin work quicker, plus a round of dependency updates.

## Generated passwords in forms

Formula fields can now generate values, not only compute them. New functions build memorable passwords and other random strings:

- `word(min,max)` picks a word of that many letters from a built-in word list
- `num(n)` and `special(n)` add digits and symbols
- `rand(a,b)` and `pick(…)` choose a number or one of a list
- `upper(s,n)` and `lower(s,n)` change the first `n` characters
- `minlen(expr,min[,max])` re-rolls until the result fits the length

For example, `minlen(upper(word(4,8),1) ~ word(4,8) ~ num(2) ~ special(1), 12)` gives something like `Maplecanyon48!`. A generated value stays put when the ticket's fields are recomputed. A **↻ New** button on the ticket rolls a fresh one. Mark the field sensitive so it's treated like the password it is.

![A ticket's custom fields with a generated temporary password and the New button](/blog/v0-12-0/formula-password.png)

**How to use:** add a computed field under Admin → Forms / Fields and write its formula with the functions above.

Custom fields also got a round of fixes:
- Values no longer disappear from the ticket page after you change its status or assignee.
- Saving one field keeps unsaved edits in the others.
- Date fields show the right day.

## Inventory bulk actions

The Inventory list has checkboxes now. Select a few assets, or all of them, and a bar appears:
- **Set type…** and **Set company…** change them together.
- Admins and Managers also get **Convert to manual** and **Delete**.

Bulk deletes and conversions are audit-logged.

Assets synced by an integration that has since been removed or disabled used to be stuck: they couldn't be fully edited or deleted. They're now flagged **Source removed**, and the source filter has an **Integration removed** option to list them. Delete them, or convert them to manual assets, which makes every field editable and stops any sync from matching them again.

![Inventory with two assets from a removed integration selected and the bulk action bar open](/blog/v0-12-0/inventory-bulk-actions.png)

## Disabled users step aside

Admin → Users hides disabled accounts by default. A **Show disabled** toggle, remembered per browser, brings them back. Deleting a user who has ticket history used to fail with a bare "Database error". It now explains that the account can't be deleted, only disabled.

## Runbooks that include runbooks

A Trove KB runbook can now include other runbooks. A step that links to another runbook opens into its steps on the ticket, numbered 2.1, 2.2 and so on, and ticking the step ticks them all.

## Also in this release

Dependency updates across the backend (12 packages) and frontend (4), and `googleapis` 183 → 189.

## Upgrade notes

Nothing to do by hand: no schema changes, no new environment variables. Installs on automatic updates pick it up with their next update. `v0.12.1` followed with dependency updates only.
